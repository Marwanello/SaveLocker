The marks

Three approved marks. Pick one per surface and keep it — a changed icon reads as a different app. Pixel lock is the default.

Rules

Clearspace is half the mark's height on every side. Nothing crosses it — not a wordmark, not a badge, not a screenshot edge.
Never: recolour the punched shape, rotate the mark, add a stroke to the solid version, place it on a busy photograph, or stretch it to a non-square box. The mark is square; if the space is not, pad it.
Colour: the body takes the accent, the punched shapes take --on-accent. The monochrome version is one colour and no punch — use it in a Steam panel, a tray, or anywhere the accent would fight the host.
02

Colour

Twelve tokens and three status hues. Every soft, border and ink step is derived with color-mix, never hand-picked.

Surface and text

system

Status

Healthy

Server and machine agree. No action is offered, because none is needed.

Warning

Failed but retrying. The copy always says what happens next. Clears itself.

Decision

A conflict or a choice. Never self-heals, always carries the control that ends it.

The accent doubles as the brand colour, so it can never be used for emphasis or decoration. If something is accent-coloured, it wants an answer.

Derivation

--accent-soft: color-mix(in oklab, var(--accent) 14%, var(--panel));
--accent-line: color-mix(in oklab, var(--accent) 42%, var(--panel));
--accent-ink:  color-mix(in oklab, var(--accent) 80%, var(--fg));
The same three lines apply to --safe and --watch. Because the mix is against --panel and --fg, a soft background stays readable in both themes without a second set of values.

Accents

user-selectable, set in the app's own settings
None of the five sit in the green or amber hue ranges, so changing the accent can never make something read as healthy or broken. Stealth is the monochrome option: the status trio then carries every colour on screen.

05

Motion

One curve, four durations. Hover the buttons above to feel it — everything uses the same easing so the whole app moves like one object.

The curve

--ease: cubic-bezier(.2, .8, .25, 1);
Canvas sectionsrise 260ms26ms stagger
Grid tilespop 300ms35ms stagger
Rows160ms2px translate on hover
Buttons130–160ms−1px hover, scale .96 press
Toggle knob260msslight overshoot
Progress550mseases, never jumps
Toast340ms in2.6s dwell

Rules

Stagger the first six children only. Past that the delay outlives the reader's patience; everything after gets the last delay.
A progress update must not re-render its surroundings. If a tick rebuilds the view, every entrance animation replays and the page appears to flash. Progress owns its own component; nothing above it re-renders.
Never animate what the eye has to track. Numbers change instantly; only the bar that represents them moves.
Everything off under prefers-reduced-motion, including the staggers.
06

Steam artwork

Four crops of one lockup, generated from the chosen mark and accent. Shown here at roughly a third scale.

The vertical capsule puts the mark at the top and the wordmark at the bottom, because Steam overlays a progress bar and a Play badge across the lower third of a grid tile. The wide and hero pieces are the same lockup at two crops, so a shelf of SaveLocker art reads as one set.
Keep the sources as SVG plus exported PNG. Nothing depends on the gradient — drop the lockup on a flat accent and it still holds.

Tokens to paste

The dark set, the light set, and the derivations. Drop into web/src/index.css as a Tailwind v4 @theme block.

:root{
  --ink:#f5f3ef; --panel:#fffefc; --raise:#f0ede8; --tile:#ebe7e0; --hover:#e8e3dc;
  --fg:#191719; --dim:#57534d; --faint:#8b8780; --line:#e2ddd5; --row:#eeeae3;
  --safe:#4c7b3e; --watch:#8a6212; --accent:#c0432c; --on-accent:#fff8f6;
}
:root:not([data-theme="light"]) @media (prefers-color-scheme: dark),
:root[data-theme="dark"]{
  --ink:#0f0f10; --panel:#141416; --raise:#191a1c; --tile:#1b1c1f; --hover:#202124;
  --fg:#f0eee9; --dim:#a09d97; --faint:#6b6862; --line:#242427; --row:#1d1d20;
  --safe:#7fa96a; --watch:#d9a63f; --accent:#e0533c; --on-accent:#160f0e;
}
:root{
  --accent-soft: color-mix(in oklab, var(--accent) 14%, var(--panel));
  --accent-line: color-mix(in oklab, var(--accent) 42%, var(--panel));
  --accent-ink:  color-mix(in oklab, var(--accent) 80%, var(--fg));
  /* same three for --safe and --watch */
  --ease: cubic-bezier(.2, .8, .25, 1);
}
One trap: the console's current index.css has an unlayered * { padding: 0 } reset that beats every Tailwind utility regardless of specificity — which is why so much of the existing UI is written with inline styles. Move the reset into @layer base before adopting these tokens, or the same workaround spreads into new code.
