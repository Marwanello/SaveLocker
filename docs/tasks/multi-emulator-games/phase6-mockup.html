tasks/multi-emulator-games · Phase 6

The agent shows one game per title, and copies a save to another emulator

The console already shows Metroid Prime - Hunters once, with a tab per emulator (Phases 1–5, variation A). Phase 6 brings the same to the agent UI: the Windows tray window and the Deck in Game Mode, which run the same React app. It also adds Copy this save to another emulator, for pairs whose formats match: DS .sav ⇄ RetroArch .srm, and Dolphin ⇄ PrimeHack. Everything in the window is clickable. Open a game, switch emulator tabs, and use Copy to… on a version. Switch the surface to see the Deck's view with controller hints.
