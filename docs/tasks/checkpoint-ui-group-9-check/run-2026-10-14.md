## Findings

1. **F1 — "Backups to keep" cannot be set back to 7 (P3, UI).** The select
   (`ConfigView.tsx:546-547`) offers `[2,4,8,12,26,52] + current`. After choosing 2, **7 disappears**
   and checklist 2.5's "set keep back to 7" is impossible from the UI; it needed an API call. Fix
   candidates: always include the default, or make it a number field.
2. **F2 — checklist 3.1's premise is stale (not a product bug).** A console-side resolve queues a
   *guarded* pull (PR #64-67 deliberately kept server-queued pulls guarded), and a machine whose save
   was never synced refuses it (`BLOCKED pull … Push first`) and re-conflicts on its next save
   (`CONFLICT: your save diverged`). "Wait until Conflict Game shows a new Latest" therefore can't
   succeed in this setup; the restore/undo path itself is unaffected. The rig was unblocked with an
   admin resolve + `savelocker pull all --force`.
3. **F3 — checklist literals.** The live DB in the container is `/data/localgamesync.db` (3c's
   `docker cp …/savelocker.db` fails as written; the name inside backup zips is still
   `savelocker.db`). The "What's new" tab renders a typographic apostrophe.
