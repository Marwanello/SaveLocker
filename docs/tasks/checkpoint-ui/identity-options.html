How to read these

The five are not one layout in five colourways. Each moves something structural, so you can judge the idea and not just the palette:

  • Cold Storage keeps today's two-pane shape but moves the brand off green onto brass, drops radii to 3px and fuses the stat row into one hairline block. Smallest jump from what ships now.
  • Checkpoint drops the game sidebar for a full-width canvas and pill chips. Fewer rows on screen, but the game you are working on gets the whole window.
  • Ledger is the only light option and the only serif one. Versions, commands and audit stop being cards and become one continuous ruled stack — it reads like the record it is.
  • Shelter doubles padding and halves the column count, and the agent moves to top tabs so no control sits under a thumb resting on a Deck grip.
  • Hangar goes the other way: zero radius, 1px seams, uppercase state codes, and nav collapsed to a 58px rail so fleet tables get the full width.

All five keep the semantics the console already uses: green or olive is healthy, amber is a warning that self-heals once the machine syncs cleanly, red is a conflict that never does. Accent and status colour stay separate families in every palette, so the brand hue never has to mean "fine".

Content is the live shape of the current UI: the version table (Version / When / Machine / Size / State / Action), the remote command queue, per-machine save paths, retention and exclude globs, the agent's connection panel, tracked-game list, and the this-device vs the-cloud conflict picker.
