What changed in this revision

The notifications menu, which was the actual question

There is now a bell in the console header with a live menu behind it — open it on the Console screen. Every problem an agent reports lands there, worst first, each with its event code, machine and time. The badge counts only what is actionable, Error and Warning; Info sits in the list without colouring anything. Dismiss hides the notice, not the condition — if the agent reports it again it comes back. This is the only route a headless Deck's failures have to a person, so it is deliberately the one control that cannot be quiet when something is wrong.

Exclude patterns are editable, and in two places

Per game: Games → the game → Exclude patterns, next to Rules. Patterns are chips you can remove, with an add field, a preview of what the next push would skip, and the server defaults shown underneath as dashed chips so it is obvious what is inherited rather than set here. Server-wide: Configuration → Defaults & maintenance, where the same editor sets the list every game inherits. They stack — a game's patterns are added to the defaults, never replace them.

Archivo everywhere

Archivo is now the default for both headings and data, with tabular figures doing the work monospace used to. Three alternates left in the switcher: Archivo / Chivo, Bricolage / Archivo, and Bricolage / Azeret if you want the mono back.

Decky redesign dropped

Removed. The plugin keeps the Steam-native look it already has; nothing in this prototype touches it. Deck / Wayland now shows just the two surfaces that are ours — the gamepad UI in Game Mode and the agent in a Wayland desktop session.

Notification content uses the real AgentEventCodes vocabulary — sync.conflict, push.failed, savedir.missing, server.unreachable, update.staged — and the same severity rule the console already applies: Info never drives the badge, and a conflict is the one entry that never clears itself.
