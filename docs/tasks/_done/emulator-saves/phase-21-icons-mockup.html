The icons in the console and the agent

Full screens with the icons in place. Emulators use Arcticons line icons, consoles use RetroArch Monochrome glyphs, and the gaps are filled as you chose: RPCS3 and ScummVM use their official logos flattened to one colour, PCSX2 and shadPS4 use the PS2 and PS4 glyphs, and Model 2 and Supermodel use the MAME glyph. Only Cemu is still a stand-in drawn here, marked in amber. Every icon is recoloured to the theme.

RPCS3’s logo comes from rpcs3/rpcs3.svg in its repository (the branding page sits behind a bot check). ScummVM’s comes from scummvm-media: its single-colour “tinted” logo, with the S cut out of the shape. Credits would go in NOTICE.md: Arcticons CC BY-SA 4.0, RetroArch assets CC BY 4.0, plus a line for the RPCS3 and ScummVM logos. A project’s logo can carry its own trademark terms beyond the code licence, so we’d check both projects’ terms before shipping.
