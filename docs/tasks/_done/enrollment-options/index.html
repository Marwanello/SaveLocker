Enrollment, three easier ways

The enrollment file works, but it is the most awkward moment in the product: a one-time JSON you download once (it cannot be shown again), carry to the machine, and race against its 15-minute expiry — and the agent UI itself cannot even open one, so the tray user has no path to it at all. These are three replacements, each a clickable walkthrough through the real console and agent UI.
Today
What the file costs
Download \u2192 copy over USB / scp / network share \u2192 savelocker enroll --file (or the installer\u2019s browse button). Single-use and unrecoverable if the download is lost; 15 minutes default TTL; no import in the agent UI on the tray.
Option A

Short code

The console shows an 8-character code; the new machine types it in. Nothing to carry, nothing to lose.
  • Console: K7QM-4H2X, copy button, live expiry
  • Agent UI: Settings \u2192 Join with a code (or enroll --code)
  • Deck: the gamepad keyboard types it with a controller
Open the walkthrough
Option B

Join link

One URL does the install and the enrollment. Open it on the new machine (or scan the QR) — nothing to type there.
  • Windows: the installer enrolls as it installs (the link fills in the file it used to ask you to browse for)
  • Linux / Deck: one curl | sh line, pastes into SSH
  • Agent already installed? The page hands off to it with one click
Open the walkthrough
Option C

Ask & approve

The device asks to join; the console approves with one click. No credential ever moves.
  • Agent finds the server on the LAN (mDNS) or you type it once
  • Console: a bell notice + Join requests card, with a code to match
  • The Plex / Steam Link motion — zero typing, zero copying
