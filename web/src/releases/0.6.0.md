# v0.6.0

_Released 4 October 2026_

**SaveLocker has a new face — everywhere at once.** This release is the Checkpoint redesign: one design
system across the web console, the agent UI on every PC, the Windows tray and the Steam Deck's Game Mode
screen. Same type (Archivo), same colours, same components, and one place to set the look for the whole
fleet. Along the way it picked up things the old screens never had: **Sync all** with live progress and
a Cancel, real OS notifications, a game page in the agent, a Backups page that can **restore**, and the
SteamGridDB key encrypted at rest.

Three database migrations (console sessions, each machine's OS, an agent's staged update) — see *Before
you upgrade*.

## One look, set once, followed by every machine

The console's new **Appearance** card picks a theme (**System**, Dark or Light), one of six accents
(Ember, Coolant, Arcade, Cobalt, Emerald, Stealth) and one of three app icons (Pixel lock, Cartridge,
Memory card). With **Push appearance to agents** on, every enrolled machine picks it up on its next
heartbeat, about 20 seconds later: the agent UI, the Windows tray and window icon (redrawn to match a
light or dark taskbar), the favicon, the Deck's Game Mode accent — and even SaveLocker's own Steam
library art, which the agent repaints in the new colours. A machine can opt out under its own
**Settings → Follow the console**.

The default theme now **follows your OS**. Every hard-coded colour is gone from both web apps, faint text
meets 4.5:1 contrast on a card in both themes, and the Windows agent window no longer flashes dark
before a light page paints.

## The console

- **A new top bar** — pill tabs, a conflict pill that shows the oldest open conflict's age, a bell that
  always tells you something (even "nothing to report"), and a lock.
- **Sync all** — one press queues a sync on every machine. Progress runs as a rail under the top bar
  ("Syncing — 2 of 3 machines done") with a **Cancel** that withdraws whatever hasn't started yet.
- **Games** — a sidebar list or a full-width **cover grid**, and a re-laid game page: latest version,
  storage, machines and lease at a glance; version history and backups side by side; each machine's save
  folder with its own Push / Pull. No more browser `alert`/`confirm` pop-ups anywhere — confirmations
  happen in place and say what they will do.
- **Conflicts** show each machine's OS logo and the exact files and times on each side, and a listbox
  picks which machine an action targets.
- **Exclude patterns** are chips with a live preview of how many files a draft would skip, and the
  **default** list is now editable from the console instead of only from configuration.
- **Configuration**, **Audit log** (search plus machine filters), **Help** and **What's new** (a release
  history table and every machine's agent version) are all rebuilt on the same kit, and the sign-in page
  gains **Remember this browser**.

## Backups you can restore

A backup is now one zip: the database **plus every game's latest save** and a manifest, on one editable
schedule — daily or weekly, day and hour in UTC (default: weekly, Sunday 03:00). The new **Backups**
page lists them with their reason (Scheduled, Manual, Before upgrade, Before restore), downloads them
through a single-use link that streams even multi-gigabyte files, deletes them, and **restores** them:
the file is validated first, a *Before restore* backup is taken, the database is copied in live and
migrated, and any missing latest saves are put back — no restart. A snapshot is also taken
automatically whenever the server starts on a different build.

The **SteamGridDB key is encrypted at rest** with a key ring kept beside — never inside — the database
and its backups. An existing plain-text key is encrypted at the next start.

## The agent UI

- A status strip on every page with what the agent is doing, **Sync all** ("3 of 7"), live upload
  progress and a Cancel between games, ending in a summary that puts every game in exactly one bucket (uploaded,
  pulled, already current, conflict, queued, not checked, failed).
- A trimmed **Overview**, a **Games** tab (list or covers, with search) that separates games set up on
  this machine from ones only on the server, and a **game page** with Sync this game / Push / Pull, the
  server's versions, the bytes sent by the last push, Change folder and Open folder.
- **Conflicts** with a "why did this happen" card and **Recently resolved**; an **Activity** page with
  the offline queue and Open agent.log; **Add games** with real progress.
- On Linux, `savelocker open` (and a new **SaveLocker** entry in the Desktop Mode application menu)
  opens the agent UI in its own app window. The agent UI also installs as a web app.

## Steam Deck Game Mode

Six sections — Overview, Tracked games, Add a game, Conflicts, Activity, Settings — walked with L1/R1,
**Sync all on Y**, and a header with the connection, machine, battery and clock. Tracked games show
their **cover art** and a Conflict / Needs setup / Synced chip; a game's own page syncs, pushes or pulls
it, shows the server's versions and lease, and changes its folder. Adding games now shows a progress bar
in place of the button, and a rejected machine key says how to re-register instead of a bare status
code.

## Notifications that mean something

Conflicts, a lease held elsewhere, a rejected push, a refused pull, an update ready and a server
unreachable for more than five minutes now raise a real **Windows toast** or **Linux desktop
notification** — once per condition, withdrawn when it clears, never for a routine successful push. A
toast's button opens the agent UI at the exact screen. The old Windows balloons (including the offline
drainer's every-30-seconds one) are gone.

## Smaller fixes

- Syncing while the server is down no longer fails the whole run: the pull reports the server as
  unreachable and the push is queued as usual. `savelocker pull` exits non-zero when it pulled nothing,
  and the tray no longer says "force-pulled" when it didn't.
- Games with no save folder on a machine are no longer counted, synced or shown with sync actions there.
- Brand assets — Steam art, favicons and both `.ico` files — are rendered reproducibly from SVG sources.

## Before you upgrade

- **Back up `/data`.** The server takes a *Before upgrade* snapshot on its own, but three migrations run
  on first start. A downgrade after that is not a clean rollback — restore the snapshot instead.
- **Keep `/data/keys` with the database.** It holds the key that decrypts the SteamGridDB key; lose it
  and you'll just need to paste the key again.
- **Update the agents.** The redesigned agent UI, Game Mode, notifications and appearance sync all live in
  the agent. An older agent keeps working against this console, and the console flags it under
  Configuration.
