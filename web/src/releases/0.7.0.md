# v0.7.0

_Released 7 October 2026_

**A game can now sync more than one save folder.** Some games keep their saves in one place and their
settings, profiles or a second save slot somewhere else; until now SaveLocker could only follow one of
them. Every game can now have extra save folders, each synced to every machine as part of the same save,
with its own include patterns and its own folder on each PC or Deck.

One database migration (a game's extra folders, and each machine's folder per key) — see *Before you
upgrade*.

## Several save folders per game

- **Add a save folder** from the console's Save folders card, from a game's page in the agent UI or on
  the Deck, or with `savelocker add-path`. Give it a name and, optionally, include patterns so only the
  files you mean are synced. Remove one the same way (`savelocker remove-path`); it stops syncing on
  every machine, and the files on disk stay where they are.
- **Every machine gets every folder.** Where a machine's folder can be worked out from the first
  machine's (the same place under Documents, AppData, a Proton prefix…), it is mapped on its own. Where
  it can't, the machine still carries that folder's files in the background, so its saves never fall
  behind; pick the folder with **Change** and the files move in. If the folder you pick already holds
  different files, SaveLocker asks whether to keep **this machine's files** or **the cloud's copy**.
- A game that only ever had one folder is stored exactly as before: existing versions, hashes and
  upload-only-changes all carry on unchanged.
- The console's Save folders card shows each folder's template, include patterns, every machine's
  folder and **what the latest save holds in each folder**, file by file.
- `savelocker status`, `list` and `doctor` show every folder, and `doctor` checks each one.

## "Also found" — folders SaveLocker spots for you

When a game's other known save locations also exist on a machine, SaveLocker offers them as extra
folders instead of guessing. Nothing is added until you say so.

- **Add games** lists each game's "Also found" folders as checkboxes, ticked by default.
- For games you already sync, the agent asks once at start-up — **More save folders found**, one game
  at a time, in the agent window, on the Deck, and as a notification. Untick or skip a folder and it
  waits on the game's page instead of asking again; **Don't sync** makes it go away for good.
- `savelocker scan` and `status` print what was also found.

## Smaller fixes

- The agent UI's folder picker covers the whole window like the other dialogs, instead of being boxed
  inside a card.
- "Saved here" sizes in the agent UI and on the Deck count every folder of a game on that machine.

## Before you upgrade

- **Back up `/data`.** The server takes a *Before upgrade* snapshot on its own, but a migration runs on
  first start. A downgrade after that is not a clean rollback — restore the snapshot instead.
- **Update the agents.** Extra save folders are synced by the agent. An agent on v0.6.0 or older keeps
  syncing a game's main folder only, and the console flags it on any game that has extra folders. Add
  extra folders once every machine that plays that game is on v0.7.0.
