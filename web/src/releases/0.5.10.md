# v0.5.10

_Released 19 August 2026_

**Large save files now upload reliably, and Linux/Deck save detection finds more games.** This
release started from two reports on the maintainer's own Steam Deck: a large save always failed to
upload, and several installed games "I'm sure have save paths" weren't showing up at all. Both turned
out to be real bugs.

No database changes.

## Large saves no longer time out mid-upload

A save archive in the 100+ MB range failed **every single time** it tried to upload, on both a local
and a remote server — while small saves worked fine. The cause was outside the agent entirely: a
Cloudflare-proxied server enforces a fixed ~100 second cap on any single request, and at this
project's real-world upload speed that is nowhere near enough time to get 100+ MB through in one shot.

The agent now uploads in ~4 MiB chunks instead of one request, so no single request can approach that
limit. Each chunk retries on its own if a connection drops. The old single-request upload path is
untouched and still used automatically when talking to a server that hasn't been updated yet, so
updating agents and the server independently is still safe.

## Linux/Deck save detection finds more games

A relocated or Cloud-only save could be missed even for a properly installed game. Some installed
games' save data isn't where SaveLocker expected — moved to the main Steam library after being
reinstalled, or living only in Steam Cloud's own sync folder with no Proton prefix at all. Both shapes
are now checked.

`doctor` also now names an SD card that's configured but not currently inserted, instead of silently
saying nothing about the games installed on it.

Worth checking your own `scan`/`doctor` output after upgrading if a game you know is installed has
never shown up.

## The agent UI shows what's happening right now

The Overview page previously had no way to answer "is anything syncing right now" short of tailing
`agent.log`. It now shows a live card: the current phase (pull, settle, push) and game, a byte
progress bar during a push, a short rolling log of recent activity, and a **Sync now** button.

The agent UI's header also now shows which *build* is running, not just the version number — useful
on a machine running a test build alongside the installed release, where several builds can share one
version number.

## Before you upgrade

- **Update the agents** for the save-detection and chunked-upload fixes — a console-only redeploy
  gets you the server side of chunked upload, but an un-updated agent still uses the old single-request
  path.
- **This is the fork's first tagged release published under its own name.** The Docker image now
  publishes to `ghcr.io/marwanello/savelocker` and the in-dashboard "fetch agent version" feature
  points at this fork's own GitHub releases, not upstream's — see `docker-compose.unraid.yml` if you
  deploy from a copy predating this change.
- **No database changes.** Downgrading the container is a clean rollback.
